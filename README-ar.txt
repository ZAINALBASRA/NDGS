تطبيق NDGS Daily Report للأندرويد (مشروع APK)
================================================

هذا المجلد مشروع جاهز للبناء، وليس ملف APK نفسه.
لم أستطع بناء الملف داخل بيئتي لأنها لا تملك أدوات الأندرويد ولا تصل إلى مستودعاتها.
اختبرت هنا كل ما يمكن اختباره (الواجهة، حفظ PDF، الخطوط، الأيقونات، السكربتات)، لكن لم أجرّب بناء الـAPK ولا تشغيله على هاتف حقيقي.
فإن ظهر خطأ أثناء البناء، أرسل لي نص الخطأ وأصلحه.

ماذا يفعل التطبيق؟
- يفتح التقرير كاملًا بملء الشاشة، ويعمل بدون إنترنت (الخطوط داخل التطبيق).
- زر «تصدير PDF» ينشئ الملف بنفس شكل الشاشة، ويحفظ نسخة في المستندات › NDGS-Reports، ثم تظهر قائمة المشاركة لإرساله (واتساب، تيليجرام، البريد...).
- المسودة تُحفظ داخل الهاتف.


الطريقة الأولى (الأسهل): البناء على GitHub بدون تثبيت أي برنامج
------------------------------------------------------------
1) فك ضغط الملف ndgs-report-apk.zip في مجلد على الحاسوب.
2) سجّل حسابًا مجانيًا في github.com، ثم اضغط New repository.
   اكتب اسمًا مثل ndgs-report، واختر Private (مهم: أسماء مهندسي النوب مكتوبة داخل التطبيق)، ثم Create repository.
3) في صفحة المستودع اضغط «uploading an existing file»، واسحب إليها كل محتويات المجلد المفكوك (الملفات والمجلدات، ومنها المجلد المخفي .github)، ثم اضغط Commit changes.
   إن لم يظهر مجلد .github بعد الرفع: اضغط Add file ثم Create new file، واكتب في خانة الاسم:
       .github/workflows/build-apk.yml
   والصق داخلها محتوى الملف GITHUB-WORKFLOW-build-apk.yml، ثم Commit changes.
4) افتح تبويب Actions. يبدأ البناء تلقائيًا باسم Build APK.
   إن لم يبدأ: اختر Build APK من القائمة اليسرى ثم Run workflow.
5) انتظر نحو 8 إلى 12 دقيقة حتى تظهر علامة ✓ خضراء.
6) نزّل الملف من أحد مكانين:
   - تبويب Releases (على يمين صفحة المستودع)، افتح أحدث إصدار ونزّل NDGS-Report.apk.
   - أو افتح عملية البناء في Actions، وفي أسفلها Artifacts نزّل NDGS-Report-APK (ملف zip بداخله الـAPK).
7) انقل الملف إلى الهاتف وافتحه.
   إذا طلب الهاتف السماح بالتثبيت من هذا المصدر فوافق.
   إذا ظهر تحذير Play Protect فاختر «More details» ثم «Install anyway». السبب أن التطبيق غير منشور في المتجر.

إن ظهرت علامة ✗ حمراء: افتح العملية، وانسخ آخر 30 سطرًا من الخطوة الفاشلة وأرسلها لي.


تعديل التقرير لاحقًا (مثل أسماء المهندسين)
-------------------------------------------
1) في المستودع افتح www/index.html، واضغط أيقونة القلم للتعديل.
2) ابحث عن ENG (Ctrl+F) وعدّل الأسماء، ثم Commit changes.
3) يبدأ بناء جديد تلقائيًا. نزّل الـAPK الجديد وثبّته فوق القديم.
   التثبيت فوق القديم يحفظ المسودة لأن التطبيق يُوقَّع بنفس المفتاح في كل مرة (مجلد keystore).
   إذا رفض الهاتف التحديث بسبب اختلاف التوقيع، احذف التطبيق القديم ثم ثبّت الجديد (تُمسح المسودة).


الطريقة الثانية: Android Studio على الحاسوب
--------------------------------------------
المتطلبات: Node.js 22 أو أحدث (nodejs.org) وAndroid Studio بآخر إصدار.
افتح موجه الأوامر داخل مجلد المشروع ونفّذ بالترتيب:
    npm install
    npm run fonts
    npx cap add android
    npm run android:prepare
    npx cap sync android
    npx cap open android
في Android Studio انتظر انتهاء Gradle Sync، ثم من القائمة:
    Build > Build Bundle(s) / APK(s) > Build APK(s)
وسيظهر لك رابط locate للوصول إلى الملف app-debug.apk.
(في هذه الطريقة يُوقَّع التطبيق بمفتاح Android Studio على حاسوبك، فتحديثاته لا تُثبَّت فوق نسخة بُنيت على GitHub والعكس.)


الطريقة الثالثة: بدون هذا المشروع
---------------------------------
ارفع مجلد النسخة الأخف ndgs-report-pwa على Netlify، ثم أدخل رابطه في pwabuilder.com واختر Android.
هذه الطريقة تحتاج استضافة، وحفظ PDF فيها يعتمد على متصفح الهاتف.


محتويات المجلد
--------------
www/index.html              التقرير كاملًا (يُعدَّل من هنا)
capacitor.config.json       اسم التطبيق ومعرّفه (com.ndgs.dailyreport)
package.json                الحزم المطلوبة
scripts/fetch-fonts.mjs     ينزّل الخطوط داخل التطبيق ليعمل بدون إنترنت
scripts/prepare-android.mjs يضيف الأيقونة وشاشة البداية والتوقيع بعد إنشاء مشروع الأندرويد
scripts/ci-build.sh         يبني ملف APK (يستعمله GitHub)
resources/android/res/      الأيقونات وشاشة البداية
keystore/                   مفتاح توقيع ثابت للتحديثات (للاستعمال الداخلي فقط، ولا يصلح للنشر على Google Play)
.github/workflows/          خطوات البناء على GitHub
GITHUB-WORKFLOW-build-apk.yml  نسخة من ملف البناء للصق اليدوي عند الحاجة
